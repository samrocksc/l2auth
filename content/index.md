# Welcome to Learn to Auth!

I wanted to build a resource that breaks down the various methods of authentication that are out there. Many web developers use these concepts 100+ times a day without thinking about how they actually work. I wanted to uncover the mysteries of authentication and provide a somewhat comprehensive explanation for each method. My goal is to build progressively as I learn how to integrate it.

I also introduce concepts from some of the front runners in the authentication space, specifically Customer Identity and Access Management (CIAM).

## Available Topics

- [Basic Authentication](basic-auth.html) - Simple username/password authentication
- [JWT (JSON Web Tokens)](concepts/jwt.html) - Token-based authentication
- [OAuth 2.0](oauth2.html) - Authorization framework for delegated access
- [OpenID Connect](oidc.html) - Identity layer built on OAuth 2.0
- [Demystifying the Tokens](demystifying-tokens.html) - What each token does in the pipeline
- [Concepts](concepts/index.html) - Important authentication and security concepts

## About This Resource

This guide aims to demystify modern authentication systems by explaining how each works, its trade-offs, and when to use it. The information is presented in a beginner-friendly manner with technical examples and diagrams.

Start with [Basic Authentication](basic-auth.html) if you are new to the topic, then move through [JWT](concepts/jwt.html), [OAuth 2.0](oauth2.html), and [OpenID Connect](oidc.html). The [Concepts](concepts/index.html) section fills in the details.
